# Paraphrase Finetuning Experiments

This directory contains scripts to run three paraphrase finetuning experiments as requested:

1. **Experiment 1**: Train on Paraphrased → Eval on Original Test
2. **Experiment 2**: Train on Paraphrased → Eval on Paraphrased Test  
3. **Experiment 3**: Train on Original → Eval on Original Test (BASELINE)

## Quick Start

To run all experiments:

```bash
cd /home/ubuntu/Spurious_corr_paraphrase
python run_complete_experiments.py
```

This script will:
1. Check if paraphrased data exists (calls `paraphraser.py` if needed)
2. Run all three experiments
3. Display results in the requested format

## Files

- `run_complete_experiments.py` - Main script to run all experiments
- `paraphrase_finetuning_experiments.py` - Standalone experiment runner
- `paraphrase_finetuning_modified.py` - Modified finetuning script for custom datasets
- `run_paraphrase_experiments.py` - Alternative experiment runner
- `requirements_experiments.txt` - Required Python packages

## Configuration

Default settings:
- Dataset: `rotten_tomatoes`
- Model: `apple/OpenELM-450M`
- Training steps: 300
- Batch size: 64
- Learning rate: 2e-5
- Max length: 512

## Paraphrased Data

The experiments use paraphrased data generated by `paraphraser.py`. The script will automatically:
1. Check if paraphrased data exists in `pr_dataset/rotten_tomatoes/`
2. Generate it using `paraphraser.py` if missing
3. Load the paraphrased data for experiments

## Output

Results are saved to:
- `experiment_outputs/` - Individual experiment results
- `experiment_outputs/final_consolidated_results.json` - Consolidated JSON results

## Troubleshooting

If experiments fail:
1. Check that all required packages are installed: `pip install -r requirements_experiments.txt`
2. Ensure HuggingFace cache directory exists: `/opt/dlami/nvme/hf_cache`
3. Check GPU memory availability
4. Review individual experiment logs in `experiment_outputs/*/logs/`

## Manual Execution

To run individual experiments:

```bash
# Generate paraphrased data first (if needed)
python paraphraser.py

# Run individual experiments
python paraphrase_finetuning_experiments.py
```
